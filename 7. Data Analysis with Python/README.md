## 7. Data Analysis with Python

This course contains several modules that consist of

**Module 1: Importing datasets**
* Understanding and preparing datasets

**Module 2: Data Wrangling** 
* Learning techniques clean, transform, and prepare data for analysis

**Module 3: Exploratory Data Analysis**
* Performing basic descriptive statistics, examining data distribution, grouping data, and visualizing patterns (including Pearson correlation and chi-square association test)

**Module 4: Model Development**
* Building, visualizing, and evaluating different types of regression models, including simple linear, multiple linear, and polynomial regression models, along with pipelines to streamline workflows.

**Module 5: Model Evaluation and Refinement**
* Optimizing predictive modelling and exploring overfitting, underfitting, and hyperparameter tuning.
 
**Module 6: Final assignment**
* Applying the complete data analysis workflow, from importing and cleaning data to building and evaluating models, on the real-world investment datasets.
